# Top-up-game-baru
cara daftar nib
1. Buka website OSS resmi pemerintah
Buka oss.go.id, daftar/login (kalau belum ada akun, bikin dulu pakai email & NIK).
2
2. Isi data pendirian usaha perorangan
Pilih jenis pendaftaran untuk perorangan/UMKM, isi data usaha (nama usaha bebas, alamat, jenis kegiatan usaha misal 'jasa perdagangan online').
3
3. Dapat NIB
Sistem akan otomatis menerbitkan NIB (Nomor Induk Berusaha) begitu data lengkap, biasanya cuma butuh hitungan jam, tanpa biaya apapun.
4
4. Pakai NIB itu buat daftar Xendit
Pakai NIB itu buat lengkapi data pendaftaran di Xendit, pilih jenis badan usaha 'Perseroan Perorangan / Sole Proprietorship' saat isi form.


1. Alur bisnis end-to-end & peran tiap pihak
Paham urutan lengkap: user isi form → backend generate QRIS → user bayar → Xendit kirim webhook → backend panggil API Digiflazz → diamond masuk → status update. Tiap pihak (Digiflazz, Xendit, backend, frontend) punya TUGAS SPESIFIK yang nggak bisa saling gantiin.
